    数据集与统计口径

    选择 khyper.graph.v1 格式的 JSON 描述文件。描述文件引用已准备好的 Parquet 或 TSV 节点表和边表，直接读取原路径，不上传、不复制、不生成预处理文件。

    无向图使用邻居、度数和强度；有向图还区分入与出。权重含义由数据集声明。文件必须无自环、无重复逻辑边，并保留孤立节点。

    数据格式详见项目 docs/DATASET_FORMAT.md。每次分析独立进行，切换数据集会清空当前报告。
